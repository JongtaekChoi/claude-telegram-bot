# 그룹에서 봇 쓰기

*[English](group-setup.md)*

DM 하나로도 충분하지만, 그룹은 **주제(Topics)마다 방이 하나씩** 생깁니다. 토픽마다 세션·대기열·실행이
따로 돌아서 여러 작업을 동시에 굴릴 수 있고, `/newchat` 으로 새 주제를 언제든 열 수 있습니다.
대신 **그 방에 있는 사람 전원이 봇을 부릴 수 있습니다** — 아래 [보안](#보안) 을 꼭 읽어보세요.

---

## 준비물

이미 DM 에서 봇이 동작하고 있다고 가정합니다 (아직이라면 [README 빠른 시작](../README.ko.md) 먼저).

---

## 1. BotFather 에서 privacy 끄기

**이 단계를 건너뛰면 그룹에서 봇이 대부분의 말을 못 듣습니다.**

텔레그램 봇은 기본적으로 *privacy mode* 가 **켜져** 있습니다. 이 상태에서 그룹의 봇에게 전달되는 건
이것뿐입니다:

- `/` 로 시작하는 명령
- `@봇이름` 을 붙인 멘션
- 봇의 메시지에 대한 답장

그래서 그냥 `테스트 좀 돌려줘` 라고 치면 **봇에게 아예 도착하지 않습니다.** 봇이 고장 난 것처럼 보이는데
로그에도 아무것도 안 남습니다 — 텔레그램이 아예 안 보낸 거니까요.

[@BotFather](https://t.me/BotFather) 에서:

```
/setprivacy → 봇 선택 → Disable
```

`Success! The new status is: DISABLED.` 가 뜨면 됩니다.

> **이미 그룹에 들어가 있는 봇이라면 한 번 내보냈다 다시 초대하세요.** privacy 설정은 초대 시점에
> 굳어져서, 설정만 바꾸면 이미 들어가 있는 방에는 반영되지 않습니다.

**대안:** privacy 를 켜 둔 채로 **봇을 그룹 관리자로 올려도** 됩니다. 관리자 봇은 privacy 설정과 무관하게
모든 메시지를 받습니다. 주제(Topics)를 쓸 거면 어차피 관리자 권한이 필요하니 이 쪽이 편할 수 있습니다.

---

## 2. 그룹 만들고 봇 초대하기

1. 텔레그램에서 새 그룹을 만듭니다 (혼자만 있는 그룹도 괜찮습니다).
2. 봇을 멤버로 초대합니다.
3. 주제(Topics)를 쓸 거라면 — 그룹 정보 → 편집 → **Topics** 켜기.
4. 봇을 **관리자**로 올리고 **주제 관리(Manage topics)** 권한을 줍니다. `/newchat` 에 필요합니다.

> **주제를 켜면 채팅 ID 가 바뀝니다.** 일반 그룹에서 Topics 를 켜면 텔레그램이 그 방을 슈퍼그룹으로
> 승격시키면서 `-100…` 으로 시작하는 **새 ID** 를 발급합니다. 봇은 이 승격을 자동으로 따라가고
> (세션까지 옮깁니다) `allowedChatId` 를 고치라고 알려줍니다 — 단, **원래 허용돼 있던 방**에서
> 출발한 승격만 따라갑니다. 그러니 **주제를 먼저 켜고 나서** 3단계로 넘어가는 게 깔끔합니다.

---

## 3. 봇이 알려주는 채팅 ID 를 `allowedChatId` 에 넣기

봇은 초대되는 순간 그 방에 이렇게 말합니다:

> 👋 이 방에 들어왔지만 아직 허용 목록에 없습니다 — 등록되기 전까지는 여기서 하는 말을 전부 무시합니다.
>
> 이 방의 채팅 ID 입니다:
> `-1001234567890`

메시지가 안 보이면 그 방에 아무 말이나 한 번 던져 보세요 (privacy 가 켜져 있으면 `/id` 처럼 명령으로).
같은 안내가 옵니다. **방마다 한 번만** 보내므로, 다시 보고 싶으면 봇을 재시작하세요.

받은 ID 를 설정 파일에 넣습니다. `allowedChatId` 는 문자열 하나든 배열이든 받습니다:

```json
{
  "allowedChatId": ["123456789", "-1001234567890"]
}
```

첫 번째가 기존 DM, 두 번째가 새 그룹입니다. **봇을 재시작해야** 반영됩니다 (`/restart` 또는 데몬 재기동).

> **토픽은 따로 등록하지 않습니다.** 화이트리스트는 채팅 ID 단위라, 그룹을 한 번 허용하면 그 안의
> 모든 주제가 함께 열립니다. 세션만 주제별로 갈릴 뿐입니다.

---

## 4. 확인

그룹에서:

```
/status
```

버전과 상태가 돌아오면 끝입니다. 이제 주제를 나눠 쓰면 됩니다:

| 명령 | 하는 일 |
| --- | --- |
| `/newchat [이름]` | 새 주제를 만들고 거기서 새 세션 시작 (`/newtopic` 도 같은 명령) |
| `/new` | 지금 방의 세션만 초기화 |
| `/id` | 이 방의 채팅 ID (와 주제 ID) 확인 |
| `/sessions` | 지난 세션 목록에서 골라 이어가기 |

---

## 보안

**화이트리스트는 사람이 아니라 *방* 단위입니다.** 그룹을 허용하면 그 방에 있는 사람 전원이 봇을 통해
당신의 프로젝트에서 Claude 를 돌릴 수 있습니다 — 파일 수정, 명령 실행 모두 포함입니다.
누군가를 그 그룹에 초대하는 건 그 사람에게 봇을 넘기는 것과 같습니다.

- 전용 **비공개 그룹**을 쓰고, 초대 링크는 돌리지 마세요.
- 그룹 관리자만 사람을 추가할 수 있도록 잠가두세요.
- 봇 토큰이 샜다고 판단되면 [@BotFather](https://t.me/BotFather) 의 `/revoke` 로 즉시 폐기하세요.
- 모르는 사람이 봇을 자기 그룹에 끌어다 넣더라도, 그 방이 `allowedChatId` 에 없으면 봇은 위의 안내
  한 줄만 남기고 아무 일도 하지 않습니다.

## 잘 안 될 때

| 증상 | 원인 | 해결 |
| --- | --- | --- |
| 그룹에서 봇이 아무 반응이 없다 | privacy mode 가 켜져 있어 메시지가 봇에 안 닿음 | BotFather `/setprivacy` → Disable **후 재초대**, 또는 봇을 관리자로 |
| 명령(`/status`)에는 답하는데 일반 대화는 씹는다 | 같은 원인 (privacy 는 명령만 통과시킴) | 위와 동일 |
| 초대해도 안내 메시지가 안 온다 | 이미 그 방에 안내를 보낸 적이 있음 | 봇 재시작 후 `/id` |
| 잘 되다가 갑자기 전부 무시한다 | 주제를 켜면서 슈퍼그룹 승격 → 채팅 ID 변경 | 봇이 새 ID 를 알려줍니다. `allowedChatId` 갱신 후 재시작 |
| `/newchat` 이 실패한다 | 주제 기능이 꺼져 있거나 봇에 *주제 관리* 권한 없음 | 그룹 편집에서 Topics 켜고, 봇 관리자 권한에 주제 관리 추가 |
| 명령이 다른 봇에게 먹힌다 | 한 방에 봇이 여럿 | `/status@내봇이름` 형태로 지정 |
